# sample-cast-py

A RESTful API server for playing samples using HTTP requests

## Setup

1. Clone the repo: `git clone git@github.com:mastergray/sample-cast-py.git`
2. Setup a virtual enviroment: `/usr/bin/python3.10 -m venv venv`
3. Start the virtual enviroment: `source venv/bin/activate`
4. Install dependencies: `pip install -r requirements.txt`
